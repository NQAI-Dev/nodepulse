Не просто HTTP-проверка, а полная картина

UptimeRobot скажет, что сайт не отвечает. NodePulse скажет — почему: упал Docker-контейнер, закончилось место, или PostgreSQL недоступен из-за просроченного сертификата.

🐳

Docker-телеметрия

Мониторинг всех контейнеров на хосте: CPU, RAM, рестарты, healthcheck. Алерт при падении.

🔒

TLS-сертификаты

За 30 дней до истечения — предупреждение. За 7 дней — критический алерт в Telegram.

🌐

HTTP / TCP / DNS / ICMP

Probes всех уровней: от пинга до banner-grabbing PostgreSQL и Redis. Один агент — все проверки.

⚙️

systemd units

Следит за состоянием сервисов: nginx, postgres, redis. Автостарт при crash.

📊

Public status page

Красивая публичная страница для клиентов: pulse.nqai.es-cloud.ru — ваша за 30 секунд.

🤖

Alerts в Telegram

Inline-кнопки: «Acknowledge» и «Resolve» прямо в уведомлении. Без перехода в браузер.

🛡️

Auto-heal

Агент сам перезапускает упавшие контейнеры по стратегии (db / cache / stateless). Dry-run режим.

🔌

Webhook-интеграции

Slack, Discord, генераторы тикетов, свои сервисы. Подписанные payload'ы, retry с backoff.
